# CodeIgniter Starter Product and Walking-Slice Acceptance

## Local authority

This repository owns CodeIgniter-relevant product scope, walking-slice acceptance, architecture, documentation, and build evidence. Fight Common portfolio requirements are bootstrap provenance only; they do not compete with this repository’s local planning or ticket status authority.

CodeIgniter owns native configuration, service discovery, HTTP, Spark console, and presentation composition. Fight Common and Fight AccessControl are public Composer packages only. There is no copied shared Domain or Application source.

## Bootstrap and acceptance boundary

The bootstrap establishes a governed hello-world foundation. Login, persistence, browser journeys, releases, tags, Packagist publication, template enablement, and create-project distribution require separately adopted local tickets. Acceptance is `./bin/build`, hosted CI delegating to that exact command, a native controller/view integration check, governance checks, and a later immutable clean-clone receipt.
