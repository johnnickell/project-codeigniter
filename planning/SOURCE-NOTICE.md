# Planning guidance and tooling provenance

The planning templates and `scripts/planning_portfolio.py` / `scripts/archive_planning.py` are adapted from
Fight Agent OS revision `a39bfc3b24ee1d7e8b782d0713b06c34ca544c6d`. Its planning conventions define the comparison
baseline; CodeIgniter owns the resulting local policy, records, migration choices, and tool maintenance.
No Agent OS product plans, approvals, runtime, or package source are imported.

Local adaptations include cumulative generated-block updates within one file, the existing Wayfinder Gate
column, and CodeIgniter's identity migration and decision frontier. See [MIGRATION.md](MIGRATION.md).
