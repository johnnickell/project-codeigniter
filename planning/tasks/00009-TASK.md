# Qualify the latest stable Fight package baseline

## Outcome

Deliver a dated recommendation for the latest mutually compatible, installable stable Fight Common and Fight
AccessControl releases, with exact references and bounded CodeIgniter consumer migration scope. Inspect each
package's latest stable release, not just the former Common 1.2+/AccessControl 0.4+ floors. If the latest pair
cannot be qualified, report concrete blockers and any proposed older alternative for explicit human decision;
do not silently downgrade the target. This is a qualification/documentation chore, normally one PR, not an
upgrade. Actual consumer implementation remains [TICKET-00008](../tickets/00008-TICKET.md).

## Scope

- In scope: authoritative release artifacts/documentation, exact versions/references and compatibility constraints;
  comparison with the current manifest, lock and installed metadata; relevant public capability/migration inventory;
  CodeIgniter composition and consumer verification consequences; a proposed WF-001 baseline reconciliation.
- Record durable, cited findings under `planning/wayfinder/research/` and link them from TICKET-00006 and this TASK.
- If the latest stable release crosses a major-version boundary, identify the migration artifacts and reconcile
  overlapping TASK-00003 ownership before expanding that investigation. Do not silently exclude the newest
  stable major or authorize its implementation; missing migration evidence is a concrete blocker.
- Out of scope: changes to project dependencies, runtime source or behavior; speculative unreleased Common 2.0
  research; new application journeys, persistence or login implementation; broader engineering alignment;
  certification receipts/lanes; copied package source, compatibility-concealing aliases, package publication,
  or closing Wayfinder decisions.
